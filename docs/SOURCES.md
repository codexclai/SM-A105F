## Samsung FUS firmware lead — researched, not used (2026-09-26)

The public third-party repository [chenxiaolong/samfusdl](https://github.com/chenxiaolong/samfusdl) is an **unofficial** Samsung Firmware Update Service client. Its observed master ref is `6cf3dc846b48891dcc48d7e97ae335fcc6fcdfb0`; GitHub marks the repository archived/read-only (archived 2024-03-11), and its README says development ended. README blob SHA: `f0de9b3c0c2b70c38c48e89485449e9e8d4a005a`.

The README says access requires two encryption keys which are not included and must be separately obtained, and that FUS now requires a device IMEI (or a serial for a device without a modem), so arbitrary device firmware downloads are no longer supported. It also expressly directs users not to ask the author how to reverse-engineer official clients. The tool's GPLv3 license covers that client, not Samsung firmware. See the [upstream README](https://github.com/chenxiaolong/samfusdl/blob/6cf3dc846b48891dcc48d7e97ae335fcc6fcdfb0/README.md) and [upstream license](https://github.com/chenxiaolong/samfusdl/blob/6cf3dc846b48891dcc48d7e97ae335fcc6fcdfb0/LICENSE).

This is not an appropriate acquisition path for this project at present: it would require a sensitive device identifier and reverse-engineered client keys, and is not an official documented download workflow. Do not request or transmit the user's IMEI/serial, extract keys, or run this client. No Samsung firmware bytes were downloaded. The official Samsung Open Source Release Center listing for build `A105FDDS9CWB3` remains a source-code listing only; its download page timed out in this environment, and the archive bytes remain unobtained. Listings, changelogs, and the existence of FUS are not firmware inputs.

Samsung's official Release Center also exposes an [Open Source Inquiry](https://opensource.samsung.com/requestInquiry) route, an indexed official page titled “Samsung Open Source Inquiry.” Direct retrieval of that page through the available web fetch returned HTTP 520 during this investigation; the form was not inspected or submitted. Treat it only as a lawful official contact option if ordinary download access remains blocked, not as evidence that a source request was made.
